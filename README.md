## まず、これを見てください

こんなこと、ありませんか。

- 数字が気になって、休みの日にも管理画面を開いてしまう
- 毎朝、同じ場所を見て、同じ表をつくり直している
- 確認と差し戻しのやりとりだけで、1日2日が溶けていく

どれも頭を使う仕事ではない。それでも手放せずにいた作業だ。この種の作業が、いまの広告運用の現場ではまとめて置き換わり始めている。

数字で見ると、こうなる。

- **1ヶ月**かかっていたSNS投稿の企画立案が → **20分**
- **10時間**かかっていた記事1本の執筆が → **数十分**
- 毎朝**30分**かかっていた数値確認が → **ゼロ**

どれも特別な大企業の話ではない。数十人規模の会社で、いま実際に起きていることだ。🔶

**3年前とは、やり方そのものが変わった。** 2023年ごろのAIは「文章の下書きを手伝う道具」で、人が指示してAIが返し、結局その先の作業は人がやっていた。今は、Slackで一言頼めば裏でAIが業務を最後まで実行し、人は判断だけして作業からは離れられる。便利になったという話ではなく、仕事の進め方の前提そのものが入れ替わっている。

**経営から見ると、数字が動く話でもある。** 1人あたりの売上が上がる、外注していた素材制作の費用が圧縮されて利益率が変わる、「人手が足りないから採る」という採用の前提を見直す会社も出てきている。🔶

そして、これは広告業界だけの話ではない。2社が自動化した業務は、業種を問わない[3つの型](#5-業種を問わない3つの型)に整理できる。経理でも人事でも営業でも製造でも、同じ考え方がそのまま当てはまる。

## この資料について

密着取材を受けた実在の広告代理店2社——SNSマーケティングのFooot（and rootsグループ）と、広告代理店Route66——の事例をもとに、Slack一言でClaude Codeが動きNotionに仕上がる自動化から、Codex×Claude Opus 4.8のダイナミックワークフローを使った経営管理の自動化まで、広告運用の現場でAIエージェントが今どこまで来ているかを整理する。あわせて、2社が自動化した業務から**業種を問わない3つの型**を抜き出し、広告業界以外の読者が自分の仕事に置き換えられる形にした。

**この資料の読み方**: 確度は文中に ✅（公式発表・公式ドキュメントで直接確認済み）／🔶（他社のYouTube動画・独自調査などの一次情報あり。出典リンクは付けない）／⚠️（未確認・自己申告値）で表記する。

## 1. 結論とベネフィット実例

「AIに広告運用を任せる」と聞くと、まだ実験段階のように聞こえるかもしれない。しかし今回、密着取材を受けた広告代理店2社では、レポート作成・SNS企画・クリエイティブ生成・審査対応が、すでに日常業務の中でAIエージェントに置き換わっていた。

**実例①（Fooot）**: 各案件のLPをスクリーンショットで確認し数値を照合する日次レポート作業に、毎朝30分＋数値の食い違いによる手戻りが発生していた。AIエージェント化後は結果がSlackに自動通知される形に変わり、この作業自体がなくなったという。🔶

**実例②（Route66）**: 広告クリック後に見せる紹介記事（KLP）の執筆に、慣れた担当者でも1本あたり約10時間かかっていた。商品LPのURLを渡すだけで分析・構成・執筆まで行うAIエージェントを構築し、大幅に時間を圧縮している。🔶

いずれも、動画内での担当者の発言・実績としての紹介であり、Claude側で数値の裏取りができているわけではない点には留意したい。

## 2. なぜ今なのか：業界の温度感

広告業界向けの独自調査（Eyez、468名対象、2026年4月発表）によれば、広告業界の約9割が業務で生成AIを活用し、約6割が「毎日利用している」と回答。企画書・提案書の作成に活用している人は約8割にのぼる。✅ [出典](https://www.eyez.jp/info/20260416/)

一部の先進企業だけの取り組みではなく、業界全体がすでに「AIを使うのが当たり前」の段階に入りつつある、というのが本資料の見立てである。

## 3. 比喩でつかむ全体像：手漕ぎボート→オートパイロットの船

本資料では、AI活用の進み方を「手漕ぎボートが、やがてオートパイロットの船になる」という比喩で通して説明する。※これは本資料側の解釈であり、事実そのものではない。

| 段階 | たとえるなら | 実際の状態 |
|---|---|---|
| Stage0 | 手漕ぎボート | 全部の業務を人が手作業でやっている |
| Stage1 | 船外機・帆を装備 | 業務ごとにAIエージェントという推進力を後付けする |
| Stage2 | 操舵室に計器が集約 | 個別の自動化がつながり、情報が1箇所に集まる |
| Stage3 | オートパイロット | 人が指示を出さなくてもAIエージェントが自律的に回り続ける |

## 4. Stage1：業務ごとの自動化（6つの実例）

今回の2社も、AI導入前はStage0（全部人力）の状態だった。🔶 全部を一気に変える必要はなく、できるところから1つずつAIエージェントに置き換えていく、というのが2社に共通する進め方だった。

1. **クリエイティブ生成**（Route66）: 実写で撮った写真・動画を「参考資料（リファレンス）」としてAIに渡し、広告用の画像・動画を生成。物理的に不可能な演出もこなす。使用ツール: Higgsfield（画像・動画生成の統合ツール）、Nano Banana（画像生成モデル）。🔶
2. **広告入稿の自動化**（Route66）: 動画3本×アカウント10個＝30本の入稿を、手作業なら数時間かかるところをワンクリックで実行。運用者が手を動かす必要のない領域だという整理である。🔶
3. **レギュレーションチェックAI**（Route66）: クライアントごとの「使ってよい表現／ダメな表現」のルールに沿って、原稿を貼るだけで一発チェック。差し戻し往復による1〜2日のロスが解消。指摘は都度データベースに追加され精度が上がっていく設計。🔶
4. **LP分析→記事の自動生成**（Route66）: 商品LPのURLを渡すと分析し、ストーリーフォーミュラに沿って記事本文を自動生成。1日200本規模で量産し、良かったものを磨き込む発想。担当者が200〜300本の当たり記事を書いてきた経験を土台に設計されている点が肝。🔶
5. **SNS投稿企画の自動化**（Fooot）: Slackで依頼すると、裏でClaude Codeが稼働し、トレンド調査・過去投稿の傾向・ミーティング議事録まで踏まえた企画案がNotionに出力される。1アカウント・月10投稿分の企画が20分、7アカウント分でも2〜3時間。🔶
6. **日次レポートの自動化**（Fooot）: 毎朝30分＋手戻りのあった数値照合が、Slackへの自動通知で作業ゼロに。🔶

Claude Code自体には、Slackでの依頼を受けてバックグラウンドで実行し、完了時に通知する公式のSlack連携機能があり、Foootの運用はこの技術的な仕組みと整合する。✅ [出典](https://code.claude.com/docs/ja/slack)

## 5. 業種を問わない3つの型

ここまでは広告代理店の話だが、2社が自動化した業務をよく見ると、業種に関係なく共通する3つの型に整理できる。※この3分類は本資料側の整理である。

### 型① 判断の型

**見分け方**: 「これはOK？ NG？」を人が毎回判断していて、その判断基準は本当はどこかに書いてある（または頭の中にある）作業。

広告代理店の例では、クライアントごとのNG表現に照らして原稿を判定するレギュレーションチェックがこれにあたる。

| 業種 | 当てはまる作業 |
|---|---|
| 経理 | 経費申請が社内規定に合っているか |
| 人事 | 応募書類が募集要件を満たしているか |
| 制作 | 納品物が仕様書どおりか |
| 開発 | コードが規約に沿っているか |
| 法務 | 契約書に見落としがないか |

**やること**: 判断基準を文章にしてAIに渡す。指摘された内容を都度追記していくと、精度が上がっていく。

### 型② 集約の型

**見分け方**: 複数の場所を見に行き、コピペして、1つの表や報告にまとめている作業。

広告代理店の例では、複数の管理画面から数値を集めて照合していた日次レポートがこれにあたる。

| 業種 | 当てはまる作業 |
|---|---|
| 営業 | 複数商談の進捗を週次でまとめる |
| 店舗 | 各店の売上・在庫を集計する |
| 経営 | 部門ごとの数字を1つのレポートにする |
| 製造 | 日々の生産実績・不良率を追う |
| 編集 | 複数媒体の反応データをまとめる |

**やること**: 情報源をAIにつなぎ、決まった形式で出力させる。全部を読ませるのではなく、異常値だけ通知させるのがコツ。

### 型③ 量産の型

**見分け方**: 毎回ゼロから考えているつもりでも、うまくいったものには共通の構造がある作業。

広告代理店の例では、過去の当たり記事の型を土台にしたLP分析→記事生成やSNS企画がこれにあたる。

| 業種 | 当てはまる作業 |
|---|---|
| 営業 | 提案書・見積書 |
| 人事 | 求人票・スカウト文 |
| 現場 | マニュアル・手順書 |
| 全職種 | 議事録からタスク一覧を起こす |
| サポート | 問い合わせ返信の下書き |

**やること**: 過去の「うまくいったもの」を数本渡して共通構造を言語化させ、それを型にして量産する。ただし、経験のないまま仕組みだけ作っても成果にはつながりにくい。型の土台には自分の成功パターンが要る。🔶

### どれから着手するか

複数当てはまる場合は、**いちばん頻度が高いもの**から1つだけ選ぶ。2社とも「まず1つ」から始めている。自分の業務を3つの型に当てはめるワークシートと、型ごとの職種別プロンプト100選は[プレゼントキット](#kit)に用意した。

## 6. Stage2：情報が1箇所に集まる

業務ごとの自動化が増えてくると、次に必要になるのは「全部を一望できる場所」になる。Route66では、Notion＋AIエージェントで、プロジェクト・タスク・マーケティング・セールス・CRM・HRという6種類のダッシュボードを構築し、会社全体の状況を1箇所に集約していた。🔶

注目すべきは「型」があれば複製が速いという点だ。参考にしたいダッシュボードのリンクをコピーし、コーディングエージェント（この事例ではOpenAIのCodex）に自社版として再現したい旨を渡すと、プロジェクトの単位やタスクのルールなど必要な事項を質問され、答えていくと自社版が1日で完成したとされる。AIがない時代なら半年規模の開発だった、という見立てである。🔶

## 7. Stage3：人が介在せず回り続ける

個々の自動化を線でつなぎ、人が指示を出さなくてもAIエージェントが自律的に回り続ける状態を「エージェンティックループ」と呼ぶ。今回の事例でも、これから取り組む次の課題として位置づけられていた、最先端の領域である。🔶

動画内では、Claude Opus 4.8の「ダイナミックワークフロー」という機能を使い、コーディングエージェントが作った設計を多角的にチェックしてから実装に戻す、という併用フローが紹介されていた。🔶 これは動画内の体験談であり、公式スペックとは別物として扱う必要がある。

Claude Opus 4.8のダイナミックワークフローは2026年5月28日にAnthropicが発表した研究プレビュー機能で、Claude Codeが計画を立てたうえで1セッション内で数百の並列サブエージェントを実行し、出力を検証してから報告する。実証として、75万行規模のコードベース移行を11日・テスト成功率99.8%で完了させた例が公式に紹介されている。Enterprise・Team・Maxプランで利用可能。✅ [出典](https://www.anthropic.com/news/claude-opus-4-8)

動画内で語られた「約560の視点から」という具体的な数字は、公式発表には見当たらない。話者個人の体感・利用実績に基づく発言とみられ、公式スペックの一部ではない点に注意したい。⚠️

## 8. 大手代理店オプトも同じ方向へ

今回の2社は中小・スタートアップ規模の事例だが、この流れは大手代理店にも及んでいる。デジタルホールディングス傘下のオプトは2026年5月18日、Anthropicの「Claude Enterprise Plan」を全社導入し、Claude中核の広告運用プラットフォーム「OPT Ad Agent」を構築したと公式発表した。MCP（Model Context Protocol）でGoogle・Meta・LINEヤフー・TikTok等の広告媒体と直結し、データ取得からレポート作成・バナー構成案の制作までをAIエージェントが自律処理する設計である。✅ [出典](https://digital-holdings.co.jp/news/20260518/2490)

中小規模の現場実装から、大手の全社導入まで、広告業界全体が同じ方向に動いていることがうかがえる。

## 9. 反論の先回り・注意点

**「AIはミスが多いのでは」**——今回の事例では、数値の取り違えはむしろ人が手作業でやっていた頃の方が多かったとされている。ハルシネーション（AIの事実誤認）よりも、人的な入力ミスの方が実害としては大きかったという整理だ。🔶 ただしこれは1社の状況であり、業務内容によって差がある点は留意したい。

**「うちは特殊な業界だから」**——今回の2社は、いずれも「まず身近な繰り返し業務」から着手している。特別なシステム開発ではなく、日々の作業の言語化から始めれば、業種を問わず応用できる考え方だと考えられる（本資料の見解）。実際に[3つの型](#5-業種を問わない3つの型)に落とし込めば、経理・人事・営業・製造など広告以外の職種にもそのまま当てはまる。

**バランスを取るための注意点**:
- 今回の事例は、いずれもAIコンサルティング企業（株式会社AX）の伴走支援を受けている。すべてを自社だけで一気に構築できるとは限らない。
- クリエイティブ生成でも、実物を手に取って写真・映像を用意した方がよい領域は残っており、AIだけに振り切っているわけではない。🔶
- AIモデルは提供停止・規制変更のリスクもゼロではない。2026年6月13日、米国政府の輸出管理指令によりAnthropicが「Fable 5」「Mythos 5」への外国籍ユーザーのアクセスを一時停止し、同年6月30日に規制解除で提供再開した例がある（約19日間の停止）。複数の技術メディアの報道に基づく参考情報。🔶

## 10. 今日からやること（始めるならこの順番）

1. 自分の業務を書き出し、[3つの型](#5-業種を問わない3つの型)のどれに当てはまるか判定する
2. 当てはまったもののうち、いちばん頻度が高い1つを選ぶ
3. その業務をAIに任せてみる（Claude Codeなどで小さく試す）
4. うまくいった型を、他の業務にも広げる
5. 複数の自動化がつながってきたら、情報を1箇所に集約するダッシュボードを検討する
6. さらに先で、人が介在しなくても回り続ける仕組み（エージェンティックループ）を目指す
