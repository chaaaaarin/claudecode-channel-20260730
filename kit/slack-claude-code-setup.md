# 🎁 Slack→Claude Code 自動化セットアップテンプレート

Slackで一言依頼するだけでClaude Codeが裏で動き、成果物がまとまって返ってくる仕組みを、自分のチームで再現するための手順テンプレートです。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 上から順にステップを進めてください。□の判定項目にYESと答えられたら次のステップへ進みます。

```text
【Slack→Claude Code 自動化セットアップ】

■ ステップ1：連携の土台を作る
□ Slackワークスペースの管理者権限があるか
→ YES: Claude Codeの公式Slack連携（Slack App）をワークスペースに追加する
→ NO: 管理者に依頼してから進める

□ 任せたい業務用の専用チャンネルを作ったか（例: #レポート自動化、#SNS企画）
→ YES: そのチャンネルにClaude Codeアプリを招待する
→ NO: 先にチャンネルを作成する
指示例: 「#日次レポート というチャンネルを作って、そこにClaude Codeを招待して」（Slack管理者向け操作。Claude Codeへの指示ではない）

■ ステップ2：任せる業務を1つに絞る
□ 「繰り返し発生する」「毎回やることが決まっている」業務を1つ選べているか
→ YES: その業務の入力（何を渡すか）と出力（何が欲しいか）を書き出す
→ NO: まず業務を書き出すところから始める（数値照合・企画立案・チェック作業などが向いている）
指示例: 「毎朝行っている◯◯業務について、入力として何を確認し、最終的に何を出力しているかを整理して」

■ ステップ3：CLAUDE.mdに業務ルールを書く
□ プロジェクトのCLAUDE.mdに、この業務の背景・ルール・出力フォーマットを書けているか
→ YES: 次のステップへ
→ NO: 下記の雛形を埋める
指示例:
## ◯◯業務の自動化ルール
- 対象: <毎朝／毎週などの頻度と対象範囲>
- 参照する情報源: <Notionのデータベース名・Slackチャンネル名など>
- チェックする基準: <具体的な判定基準を箇条書きで>
- 出力先: <Notionのページ／Slackの通知先チャンネル>
- 出力フォーマット: <見出し・箇条書き・表など、欲しい形式>

■ ステップ4：Slackからの依頼文を型にする
□ 毎回同じ言い方で依頼できる「型」ができているか
→ YES: 依頼文をチームで共有し、誰でも同じ結果が出るようにする
→ NO: 下記の指示例をベースに自分の業務用に書き換える
指示例: 「◯◯業務を実行して。対象は<期間・範囲>、結果は<出力先>にまとめて。何か判断に迷う点があれば先に確認して」

■ ステップ5：出力先（Notion等）を用意する
□ Claude Codeの成果物を貯める場所（Notionページ・データベース等）が決まっているか
→ YES: そのURL・アクセス権をCLAUDE.mdまたは指示文に明記する
→ NO: まずシンプルな1ページのメモからでも始める（後から拡張できる）

■ ステップ6：小さく試して、型を固める
□ 1回分の依頼を試し、期待した出力になったか
→ YES: 同じ型で2〜3回繰り返し、安定して同じ品質が出るか確認する
→ NO: CLAUDE.mdのルール・出力フォーマットの指定を見直して再度試す
指示例: 「さっきの出力について、◯◯の部分が期待と違ったので、次回からは<修正内容>のようにして」

■ ステップ7：他の業務へ横展開する
□ 1つの業務で安定運用できているか
→ YES: 同じ手順で次の業務（ステップ2に戻る）に着手する
→ NO: 無理に広げず、まず1つを安定させることを優先する
```

**ポイント**: 一度に全部の業務を自動化しようとせず、1つずつ「型」を固めてから横展開するのが、今回の事例に共通していたやり方です。
