# 🎁 自分の業務に翻訳するワークシート

広告代理店2社の事例から抽出した「業種を問わない3つの型」に、自分の仕事を当てはめて、最初に自動化する業務を1つ決めるためのワークシートです。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 上から順に埋めてください。ステップ4まで進むと、AIにそのまま渡せる指示文が完成します。

```text
【自分の業務に翻訳するワークシート】

■ ステップ1：3つの型に当てはめる
自分（または自分のチーム）の業務を思い浮かべて、当てはまるものにチェックを入れる。

□ 型① 判断の型：毎回、同じ基準で「OK/NG」を判断している作業がある
→ YES: その作業名を書き出す ＿＿＿＿＿＿＿＿＿＿＿＿
　（例：経費申請の規定チェック／応募書類の要件確認／納品物の仕様確認／コードレビュー／契約書の確認）

□ 型② 集約の型：複数の場所から情報を集めて、1つの表や報告にまとめている
→ YES: その作業名を書き出す ＿＿＿＿＿＿＿＿＿＿＿＿
　（例：週次の商談進捗まとめ／各店の売上集計／部門別数字のレポート化／生産実績の集計）

□ 型③ 量産の型：毎回ゼロから作っているが、うまくいったものには共通の構造がある
→ YES: その作業名を書き出す ＿＿＿＿＿＿＿＿＿＿＿＿
　（例：提案書・見積書／求人票・スカウト文／マニュアル・手順書／議事録からのタスク起こし）

■ ステップ2：最初の1つを選ぶ
□ ステップ1で複数チェックが付いたか
→ YES: 「頻度が高い順」に並べ、いちばん上の1つだけを選ぶ（同時に複数着手しない）
→ NO: チェックが付いた1つをそのまま採用する

選んだ業務：＿＿＿＿＿＿＿＿＿＿＿＿
その業務の頻度：（毎日／週◯回／月◯回）＿＿＿＿＿＿
1回あたりの所要時間：約＿＿＿分

■ ステップ3：入力と出力を言葉にする
□ その業務を始めるとき、手元に何があるか書けているか
→ YES: 次へ
→ NO: 下を埋める
　入力（見る情報・受け取るもの）：＿＿＿＿＿＿＿＿＿＿＿＿

□ その業務が終わったとき、何が出来上がっているか書けているか
→ YES: 次へ
→ NO: 下を埋める
　出力（成果物・提出先）：＿＿＿＿＿＿＿＿＿＿＿＿

□ 途中で使っている判断基準・ルールを書き出せているか
→ YES: 次へ（この基準こそがAIに渡す中身になる）
→ NO: 過去の差し戻し・指摘を3つ思い出して書く
　基準1：＿＿＿＿＿＿＿＿＿＿＿＿
　基準2：＿＿＿＿＿＿＿＿＿＿＿＿
　基準3：＿＿＿＿＿＿＿＿＿＿＿＿

■ ステップ4：AIに渡す指示文を組み立てる
下の雛形の【】を、ステップ2〜3で書いた内容で埋める。埋めたらそのままAIに貼る。

---
あなたは【業種・職種】の担当者です。以下の業務を手伝ってください。

# 業務の内容
【ステップ2で選んだ業務名】

# 渡すもの（入力）
【ステップ3の入力】

# 作ってほしいもの（出力）
【ステップ3の出力】

# 守ってほしい基準・ルール
- 【基準1】
- 【基準2】
- 【基準3】

# お願い
- 判断に迷う箇所があれば、勝手に決めずに先に質問してください
- 基準に照らして問題がある箇所は、該当部分を引用して指摘してください
---

■ ステップ5：3回試して型を固める
□ 1回目：出力が期待と違った箇所を書き出したか
→ YES: その内容をステップ4の「守ってほしい基準・ルール」に追記して2回目を試す
→ NO: まず1回試す

□ 3回連続で、手直しなしで使える出力になったか
→ YES: この指示文を保存し、チームに共有する（型が固まった状態）
→ NO: ずれる箇所をルールに追記して繰り返す

■ ステップ6：次の業務へ広げる
□ 1つ目が安定して回っているか
→ YES: ステップ1に戻り、次に頻度の高い業務を選ぶ
→ NO: 無理に広げず、1つ目を安定させることを優先する
```

**ポイント**: いちばん大事なのはステップ3の「判断基準を言葉にする」工程です。今回取材を受けた2社も、AIに任せる前に「自分たちが何を見て判断していたか」を書き出すところから始めていました。
